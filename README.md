## Lab files

| Lab | What it demonstrates |
| --- | --- |
| [Lab #1](./Lab%20%231) | Turn an LED on at BCM GPIO 18, wait one second, and turn it off. |
| [Lab #2](./lab%20%232) | Ask five Python questions and use green and red LEDs at GPIO 17 and 18 to report answers. |

The files preserve their original lab names and are useful to read as examples. The first uses Python 2 print syntax. The second needs indentation fixes and an `RPi.GPIO` import before it can run as a standalone script.
